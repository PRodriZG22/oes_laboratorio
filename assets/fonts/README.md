# Tipografía del informe PDF

Se distribuyen `DejaVuSans.ttf` y `DejaVuSans-Bold.ttf` del proyecto DejaVu Fonts, junto con `LICENSE_DEJAVU.txt`. La licencia permite redistribución y uso respetando sus condiciones. No son tipografías propietarias de Windows.

Los archivos proceden del paquete Matplotlib instalado, que los redistribuye con su licencia. Se incluyen en el repositorio para generar PDF sin descargas de red ni dependencias de fuentes del sistema. Origen del proyecto: https://dejavu-fonts.github.io/.

La fuente cubre español y muchos otros caracteres, pero no todos los sistemas de escritura ni todos los emojis. Los caracteres no cubiertos se representan con `?` y el informe avisa de la sustitución; el CSV conserva el texto original.
